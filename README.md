# Coursify Mobile

## Project Description
Coursify Mobile is the Android application of the Coursify platform — a Senior High School course recommendation system. It allows students to take a multi-dimensional psychometric and aptitude assessment directly from their phone and receive personalized, ML-ranked college course recommendations.

The mobile app is built with React Native (Expo) and communicates with the same shared Coursify FastAPI backend used by the web version. It is designed exclusively for the **student role** — admin and superadmin features are only available on the web.

## Features
- **User Authentication** — Secure registration with email OTP verification, login, forgot password with reset code flow, and JWT-based session management via AsyncStorage
- **RIASEC Assessment** — Holland Interest Inventory with 36 questions across 6 personality types (Realistic, Investigative, Artistic, Social, Enterprising, Conventional)
- **Big Five Personality Assessment** — OCEAN model personality profiling with 25 questions across 5 traits including reverse-scored items
- **Aptitude Assessment** — 12-question subject tests across Math, Science, English, and Abstract Reasoning with easy / medium / hard difficulty tiers
- **ML-Powered Course Recommendations** — Top 5 ranked college course suggestions with confidence scores generated by a scikit-learn model on the backend
- **Dashboard** — Quick stats showing top RIASEC codes, best subject, and top recommended course from the latest assessment
- **Assessment History** — View all past assessment attempts with full score breakdowns per attempt
- **Course Explorer** — Browse and filter college courses by strand and category
- **Profile Management** — Edit personal info including username, email, grade level, and academic strand

## Technology Stack

| Layer | Technology |
|---|---|
| Mobile Framework | React Native (Expo) |
| Navigation | Expo Router |
| Local Storage | AsyncStorage |
| Backend API | FastAPI (Python) — shared with web |
| Database | MongoDB Atlas |
| Authentication | JWT Tokens |
| Email Service | Gmail SMTP via aiosmtplib |
| ML Model | Random Forest (scikit-learn) |
| AI Summaries | Google Gemini (google-generativeai) |
| Hosting | Render (backend) |
| Build | EAS Build (Expo) |

## System Architecture

````
Coursify Mobile (React Native / Expo)
        │
        │  AsyncStorage
        │  ┌──────────────────────────────┐
        │  │  token · user · role         │
        │  └──────────────────────────────┘
        │
        │  REST API calls (JWT Bearer token)
        ▼
Coursify FastAPI Backend (Render)
        │
        ├── MongoDB Atlas
        │     users, questions, assessment_results
        │
        ├── scikit-learn ML Model
        │     Input:  RIASEC scores, Big Five means,
        │             aptitude percentages, strand
        │     Output: top 5 courses + confidence scores
        │
        └── Gmail SMTP
              OTP verification + password reset emails
````

The mobile app sends all requests with a `Bearer` JWT token in the `Authorization` header. On assessment submission, the backend scores the answers, runs the ML model, stores the result in MongoDB, and returns ranked course recommendations to the app.

## Installation & Setup

### Prerequisites
- Node.js v18 or higher
- npm or yarn
- Expo CLI — `npm install -g expo-cli`
- EAS CLI — `npm install -g eas-cli`
- An Expo account at [expo.dev](https://expo.dev)

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/coursify-mobile.git
cd coursify-mobile
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure the API
Open `config/api.js` and set your backend URL:
```js
const API = "https://your-backend-url.onrender.com";
export default API;
```
Use `http://localhost:8000` if running the backend locally.

### 4. Run locally with Expo Go
```bash
npx expo start
```
Scan the QR code with the Expo Go app on your Android device. Make sure your phone and computer are on the same Wi-Fi network.

### 5. Build APK for distribution
```bash
eas build -p android --profile preview
```
Once the build completes, download the APK from the Expo dashboard and install it on your Android device.

> **Note:** When installing the APK, you may need to enable **Install from Unknown Sources** in your Android settings under Security or Privacy.

## Known Limitations
- **Student role only** — The mobile app is designed exclusively for students. Logging in with admin or superadmin credentials will authenticate successfully but will not navigate to any admin features, as no admin UI or routing exists in the mobile app
- **Email delivery in deployment** — OTP verification and password reset emails use Gmail SMTP which requires outbound ports 465 or 587. Most cloud hosting providers block these ports, causing connection timeouts in production. Locally this works since the machine connects directly. The proper solution for production is to use a dedicated email API service such as SendGrid or Mailgun, which send over HTTPS (port 443) instead
- **No push notifications** — Assessment completion and other events do not trigger push notifications; students must open the app to see updated results
- **Android only** — The app is built and tested for Android via EAS Build. iOS is not currently supported as it requires an Apple Developer account and separate build configuration
- **Backend dependency** — The app requires the Coursify backend to be running and reachable. All features including login, assessment, and history are unavailable if the backend is offline or unreachable
